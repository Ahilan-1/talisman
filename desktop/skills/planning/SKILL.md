# Planning

Read `how_to_plan.md` in this folder before a task that needs more than three steps.

## When to plan

Plan when the task: touches money, travel, another person, a deadline, or more than three browser steps. Do not plan
small things — a single lookup gets a single action.

## The private plan

Write it for yourself, never as a message:

```
Goal: book two seats for Jailer 2 on 9 Nov
Known: city Chennai, 2 tickets, no time preference
Steps:
 1 find official listing
 2 read showtimes for 9 Nov
 3 pick a screening with 2 adjacent seats
 4 read total
 5 ask approval with total
 6 complete booking, verify reference
Risks: seat map is canvas; payment may block
```

## Running it

- Do steps in order, one at a time, verifying each with a read after acting.
- If a step fails twice, switch method: different site, different route, desktop.
- Keep going. Do not send progress updates; send one result.
- If a missing fact blocks step N, ask only that question, then continue from there.
- Track open threads across turns: what is done, what is waiting, what was abandoned.

## Ending

State the outcome, the reference or number that proves it, and one optional next step. Never dump the step log or
mention that you planned.
