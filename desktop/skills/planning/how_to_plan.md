# How to plan a complex task

## Worked example: a weekend trip

Them: *"Sort out a weekend in Pondicherry for two, leave Friday evening, back Sunday."*

**Private plan**

```
Goal: weekend trip, 2 people, Fri evening → Sun
Known: origin (home city), no budget given, no hotel preference
 1 confirm origin and dates from memory/conversation
 2 check trains and buses Friday evening
 3 shortlist two stays near the promenade
 4 build a Saturday outline that fits travel times
 5 present one option with total cost
 6 ask approval, then book travel first, stay second
```

**What to do while running it**

- Steps 2–4 are read-only: batch them, no questions.
- If origin is not in memory, that is the one question to ask — nothing else.
- Prices change between search and checkout; quote the checkout total.

**How it ends**

`Friday 6:40pm bus, ₹1,240 for two. Stay at Villa Rose, promenade, ₹4,800 a night, free cancellation until Thursday.
Total ₹10,840. Book it?`

## Anti-patterns

- Sending a five-bullet plan and waiting for approval. They asked for a trip, not a project charter.
- Doing step 1–3 then stopping to ask whether to continue.
- Losing thread between turns: if they answer one question later, resume at the blocked step.
- Ignoring a constraint already stated ("we don't want to fly") because it is not in the plan template.
